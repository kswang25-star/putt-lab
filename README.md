# PUTT LAB LIVE

스마트폰·태블릿 카메라로 퍼팅 스트로크를 실시간 분석하는 웹앱입니다.

- 주소: https://kswang25-star.github.io/putt-lab/
- 측정: 타점(토우/힐 mm), 임팩트 페이스 각, 어드레스 에임, 출발 방향, 패스, 템포, 볼 스피드, 헤드 속도, 스매시
- 보정: A4 용지 네 모서리로 원근 보정, 퍼터 마커 2개로 페이스 각 측정, 마이크로 임팩트 타이밍 보정
- 기록: 브라우저(localStorage)에 저장, 세션별 그래프, CSV·백업 복사

안드로이드 크롬 최신 버전 권장. 카메라와 마이크 권한이 필요합니다.
